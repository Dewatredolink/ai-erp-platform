# ai-erp-platform
AI-First Enterprise Resource Planning &amp; Accounting Platform - Production Grade ERP for Trading, Retail, Manufacturing, Pharma, and Distribution Businesses

## Frontend

A React frontend that connects to the .NET backend API lives in [`frontend/`](frontend/README.md).
It provides a Companies page (list, add, edit, delete) that talks to the backend's
`/api/companies` endpoints.
